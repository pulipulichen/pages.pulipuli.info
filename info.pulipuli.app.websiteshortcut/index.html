Privacy Policy (English)

Overview

Website Shortcut is an Android app that creates home-screen shortcuts from web links and lets you select or edit the shortcut icon. This policy describes data handling in the current app version.

The app does not require an account, use a developer-operated sync service, display ads, include analytics or tracking SDKs, or send automatic crash reports. The developer does not receive the app's local history or settings.

Information the app handles

When you share or enter a website address, the app uses that URL to request the web page and its title or icon, then to create the shortcut. The URL may contain a path or query parameters that you chose to share.

If you select or drop an image, the app reads only the image URI you provide and uses the image to make the shortcut icon. The app can also keep a small icon copy with a local history entry.

The app stores shortcut titles, URLs, creation times, pin status, icon copies, and appearance preferences locally as described below.

Network requests and third-party services

To read a shared or entered website, the app requests the page and its icon from that website. If the page does not provide usable details, the app may try a parent page address to find an icon. The destination website receives the request URL and ordinary connection information, which may include your IP address and standard request headers. The app does not send these requests through a developer-operated server.

The app accepts both HTTPS and HTTP addresses. HTTP traffic is not encrypted in transit. Use HTTPS where available and avoid sharing URLs that contain information you do not want sent to the destination website.

If you tap Search vector icons, the app opens Flaticon with the current shortcut name as a search term. If you tap Draw icon with ChatGPT, the app opens ChatGPT and includes the current shortcut name in the prompt. These actions are optional and happen only when you choose them. Flaticon, ChatGPT, and the browser you use may process those requests under their own privacy policies. The app does not upload your selected image through these actions.

When you create a pinned shortcut, Android's launcher receives the shortcut URL, title, and icon so it can display and open that shortcut. When you later tap it, your chosen browser receives the URL and handles the resulting website visit under its own privacy practices.

Local storage and retention

The app keeps its shortcut history and appearance settings in app-private storage on your device. History contains the shortcut title, URL, creation time, pin status, and a small icon copy. Appearance settings include your theme and dynamic-color preference.

The history retains the 30 most recent unpinned entries, along with pinned entries that you keep. Pinned entries can remain until you unpin and clear them. Choosing Clear history removes unpinned history entries and keeps pinned ones.

To remove a pinned history entry, unpin it and then clear the history. A shortcut already displayed by your Android launcher may need to be removed separately through the launcher. App-private history and settings are normally removed when you clear the app's storage or uninstall the app, subject to Android device behavior.

Permissions and system access

The app requests Internet access to retrieve website details and remote icons. It does not request location, contacts, camera, microphone, or broad file-storage permissions. Image selection uses Android's content selection interface to access an image you choose. Shortcut creation uses Android's launcher pinning interface.

Security

Local history and settings are kept in the app's private storage area. Network requests go directly to the website or third-party service used for a feature. No method of storage or transmission is completely secure; HTTP requests are not encrypted.

Children's privacy

Website Shortcut is a general-purpose utility and is not designed specifically for children. The app does not intentionally collect children's personal information.

Changes to this policy

This policy may be updated when app features or data practices change. The effective date above will be revised when material changes are made.

隱私權政策（繁體中文）

概要

「網站捷徑」是一款 Android App，可將網站連結建立成主畫面捷徑，並讓你選擇或編輯捷徑圖示。本政策說明目前版本的資料處理方式。

本 App 不要求建立帳號、不使用開發者營運的同步服務、不顯示廣告，也未整合分析、追蹤或自動崩潰回報 SDK。開發者不會收到 App 本機保存的歷史紀錄或設定。

App 處理的資訊

你分享或輸入網站網址時，App 會使用該網址向網站請求頁面、標題或圖示，再用來建立捷徑。網址可能包含你選擇分享的路徑或查詢參數。

你選取或拖曳圖片時，App 只會讀取你提供的圖片 URI，並用該圖片製作捷徑圖示。App 也可能在本機歷史紀錄中保存一份縮小的圖示。

App 會在本機保存捷徑名稱、網址、建立時間、釘選狀態、圖示副本，以及下文所述的外觀設定。

網路請求與第三方服務

為了讀取你分享或輸入的網站，App 會向該網站請求頁面與圖示。若頁面沒有可用資訊，App 可能改向上一層網址尋找圖示。接收請求的網站會取得請求網址及一般連線資訊，可能包括你的 IP 位址和標準請求標頭。App 不會透過開發者營運的伺服器轉送這些請求。

App 接受 HTTPS 與 HTTP 網址。HTTP 傳輸不會加密。請盡量使用 HTTPS，並避免分享含有你不希望傳給目標網站之資訊的網址。

如果你點選「搜尋向量圖示」，App 會開啟 Flaticon，並將目前捷徑名稱作為搜尋字詞。如果你點選「使用 ChatGPT 繪製圖示」，App 會開啟 ChatGPT，並將目前捷徑名稱放入提示內容。這些操作是選用功能，只有在你主動點選時才會發生。Flaticon、ChatGPT 及你使用的瀏覽器，可能依各自的隱私權政策處理請求。App 不會透過這些操作上傳你選取的圖片。

建立釘選捷徑時，Android Launcher 會收到捷徑網址、名稱與圖示，以便顯示及開啟捷徑。之後你點選捷徑時，網址會交由你選擇的瀏覽器處理，並適用該瀏覽器及網站的隱私規範。

本機儲存與保存期限

App 會在裝置上的 App 私有儲存空間保存捷徑歷史紀錄與外觀設定。歷史紀錄包含捷徑名稱、網址、建立時間、釘選狀態及縮小的圖示副本。外觀設定包含主題和動態色彩偏好。

歷史紀錄保留最近 30 筆未釘選紀錄，並另外保留你釘選的紀錄。釘選紀錄會持續保留，直到你取消釘選並清除。使用「清空記錄」會刪除未釘選紀錄，保留已釘選紀錄。

若要移除已釘選的歷史紀錄，請先取消釘選，再清空記錄。已顯示在 Android Launcher 上的捷徑可能需要另外透過 Launcher 移除。清除 App 儲存空間或解除安裝，通常會移除 App 私有的歷史紀錄和設定；實際結果依 Android 裝置行為而定。

權限與系統存取

App 要求網路存取權限，以取得網站資訊和遠端圖示。它不要求定位、聯絡人、相機、麥克風或廣泛的檔案儲存權限。選取圖片時，App 使用 Android 內容選擇介面存取你指定的圖片；建立捷徑時，則使用 Android Launcher 的釘選介面。

安全措施

本機歷史紀錄和設定保存在 App 私有儲存空間。網路請求會直接傳送至網站或提供該功能的第三方服務。任何儲存或傳輸方式都無法保證絕對安全；HTTP 請求不會加密。

兒童隱私

「網站捷徑」是一般用途工具，並非專為兒童設計。本 App 不會刻意蒐集兒童的個人資料。

政策變更

若 App 功能或資料處理方式有所變更，本政策可能更新。重大變更時會修改上方生效日期。
