About this application

Web Dashboard (OAuth application: WDB 20240106-1707) is a collection of Google Apps Script workflows. One known workflow is Bill Records — ErisStar Billing Records — AppSheet 2026, which works with configured Google Drive resources and spreadsheet-based billing records.
